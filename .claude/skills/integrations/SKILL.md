# Внешние сервисы

Клиентские настройки — `js/config.js`, серверные — начало `send.php`.

| Сервис | Где | Ключ |
|---|---|---|
| Карта (виджет Яндекс Карт) + маршруты Яндекс/2ГИС/Google | `config.js` → `map.lat/lon/zoom/address` | не нужен |
| SmartCaptcha | `config.js` → `smartCaptchaKey` + `send.php` → `$SMARTCAPTCHA_SECRET` | console.yandex.cloud, бесплатно |
| Telegram | `send.php` → `$TG_BOT_TOKEN`, `$TG_CHAT_ID` | бот от @BotFather |
| E-mail | `send.php` → `$TO` | — |
| Форма | `config.js` → `formEnabled`; на `*.github.io` форма всегда отключена (нет PHP) | — |

- Ключи капчи — только парой: один серверный без клиентского = все заявки отклоняются.
- Капча невидимая, скрипт грузится при первом фокусе в форме; если сервис капчи не отвечает, заявка не теряется.
- Координаты: Яндекс Карты → правый клик → «Что здесь?». Адрес также в `index.html` и `politika.html`.
- Секреты (ключ сервера капчи, токен Telegram) — только в `send.php`, никогда в JS/HTML и не в публичный репозиторий.
