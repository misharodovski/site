# Добавление фотографий работ

Галерея строится из `js/works.js` (генерируется) и файлов `img/works/<slug>/NN.jpg` + `NN-t.jpg`.
Руками эти файлы не правим — только через `tools/prepare_photos.py`.

1. Посмотрите содержимое: `"C:\Program Files\7-Zip\7z.exe" l -ba <архив>.rar` (имена внутри в cp866 — это нормально).
2. Новая категория — добавьте строку в `CATS` в `tools/prepare_photos.py`:
   `("ИмяАрхиваБезRar", "slug", "Заголовок", "номер обложки", "Описание")`. Порядок строк = порядок фильтров.
3. Запуск:
   `python tools/prepare_photos.py "C:\Users\DEFER\Pictures\Material"` или с `--only slug1,slug2`.
   Скрипт поворачивает по EXIF, отбрасывает мелкие (<380 px) и почти одинаковые кадры, жмёт до 1600/640 px.
4. Обложка: соберите контакт-лист превью (Pillow, сетка 8×N с номерами) в scratchpad, выберите кадр,
   впишите номер в `CATS` и перезапустите с `--only <slug>`. Хорошая обложка — изделие крупно, без мусора и дат на фото.
5. Если категория есть в «Направлениях» (`index.html`, `#projects`) — обновите путь к обложке.
6. Номера кадров меняются при пересборке — проверьте `data-open="slug:NN"` в блоке «Материалы».
7. Проверьте результат скилом `site-check`.
