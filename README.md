# Истая Кузница — сайт-визитка

Готовый сайт кузницы: Донецк + работа по всей ДНР. Обычный статический сайт (HTML/CSS/JS) с одним PHP-файлом для формы заявок. Ни базы данных, ни CMS не требуется.

## Что внутри

| Файл / папка | Зачем |
|---|---|
| `index.html` | главная страница |
| `politika.html` | политика конфиденциальности (152-ФЗ) |
| `404.html` | страница «не найдено» |
| `js/config.js` | **НАСТРОЙКИ: телефон, мессенджеры, почта, часы работы, Метрика** |
| `send-config.php` | **НАСТРОЙКИ ФОРМЫ: почта (SMTP) и Telegram для заявок** |
| `send.php` | обработчик формы (не трогать) |
| `js/works.js` | список фото работ по категориям |
| `img/works/<категория>/` | реальные фото: `NN.jpg` (1600 px) и `NN-t.jpg` (превью 640 px) |
| `img/hero.jpg`, `img/og.jpg` | фото главного экрана и картинка для ссылок в мессенджерах |
| `.htaccess` | кэширование, сжатие, закрытие служебных файлов |
| `robots.txt`, `sitemap.xml` | для Яндекса и Google |
| `data/leads.csv` | появится сам: копия всех заявок (открывается в Excel, из интернета закрыт) |

## Запуск на Timeweb — по шагам

### 1. Хостинг
1. Зарегистрируйтесь на timeweb.com → «Виртуальный хостинг» → тариф **Optimo** (или любой другой, где есть PHP).
2. Первые 10 дней — бесплатный тест. **Учтите:** на тестовом аккаунте Timeweb закрывает отправку почты из скриптов, поэтому полностью проверить форму получится после оплаты. Сам сайт работает и на тесте.

### 2. Домен
1. В панели: «Домены» → «Зарегистрировать» (например, `istaya-kuznica.ru` — проверьте, свободен ли). При годовой оплате Timeweb даёт домен .RU/.РФ в подарок.
2. Для доменов .ru/.рф администратор домена должен пройти **идентификацию через Госуслуги** — в панели Timeweb есть кнопка для этого. Пока она не пройдена, домен может не делегироваться.
3. Привяжите домен к сайту: «Сайты» → ваш сайт → «Привязать домен».

### 3. Загрузка файлов
1. В панели: «Файловый менеджер» → откройте папку сайта → `public_html`.
2. Удалите оттуда заглушку `index.html` от Timeweb (если есть).
3. Загрузите архив `kuznica-site.zip` → правый клик → «Разархивировать».
4. **Важно:** `index.html` должен лежать прямо в `public_html`, а не в подпапке `public_html/kuznica-site/`. Если он оказался в подпапке — выделите всё её содержимое и перенесите на уровень выше.
5. Проверьте, что файл `.htaccess` тоже на месте (в файловом менеджере включите показ скрытых файлов).

### 4. HTTPS (замок в браузере)
«Сайты» → настройки → **SSL-сертификаты** → «Заказать» бесплатный Let's Encrypt → после выпуска включите **«Перенаправлять с HTTP на HTTPS»**.

### 5. Контакты на сайте — `js/config.js`
Откройте файл (в файловом менеджере: правый клик → «Редактировать») и заполните:
```js
phone:        '+79491234567',          // номер для звонка
phoneDisplay: '+7 (949) 123-45-67',    // как показывать
email:        'info@ваш-домен.ru',
telegram:     'istaya_kuznica',        // без @
whatsapp:     '79491234567',
max:          '',                      // ссылка на MAX, если есть
vk:           '',
```
Пустое значение `''` — пункт на сайте просто не показывается.

### 6. Чтобы заявки приходили — `send-config.php`
> ⚠️ Токен бота и пароль от почты вписывайте **только в копию файла на хостинге** (через файловый менеджер Timeweb). Не сохраняйте их в репозиторий GitHub — он публичный, и пароли увидят все.

Заявка уходит во все включённые каналы. Настройте хотя бы один (лучше оба):

**Telegram (заявка мгновенно приходит в телефон):**
1. В Telegram найдите **@BotFather** → `/newbot` → придумайте имя → получите токен `123456789:AA...`.
2. Напишите своему новому боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` → найдите `"chat":{"id":123456789` — это **chat_id**.
4. В `send-config.php`: `'enabled' => true`, вставьте `token` и `chat_id`.
   Чтобы заявки видели несколько человек — создайте группу, добавьте туда бота и укажите id группы (с минусом).

**Почта (через SMTP Timeweb):**
1. В панели: «Почта» → создайте ящик, например `site@ваш-домен.ru`.
2. В `send-config.php` в блоке `smtp`: `'enabled' => true`, адрес ящика в `user` и `from`, пароль в `pass`, свою личную почту — в `to`.
3. Если письма попадают в спам — попросите поддержку Timeweb настроить для домена SPF, DKIM и DMARC (это бесплатно).

Даже если оба канала не настроены или временно не работают, заявка сохранится в `data/leads.csv`.

### 7. Адрес сайта в служебных файлах
Найдите и замените `https://example.com` на ваш адрес (например, `https://istaya-kuznica.ru`) в трёх файлах:
- `index.html` (3 места в начале файла),
- `robots.txt`,
- `sitemap.xml`.

### 8. Политика конфиденциальности
В `politika.html` заполните подсвеченные места: ФИО/ИП, ИНН, контакт для обращений, дату.

### 9. Проверка
- Откройте сайт с телефона и с компьютера.
- Отправьте тестовую заявку — она должна прийти в Telegram/на почту.
- Нажмите на номер телефона — должен начаться звонок.

## Продвижение (бесплатно, очень рекомендуется)
1. **Яндекс Бизнес** (yandex.ru/sprav) — карточка кузницы на Яндекс Картах и в поиске. Для местного бизнеса даёт больше всего обращений. Укажите сайт, телефон, фото работ, зону обслуживания — ДНР.
2. **2ГИС** — добавьте организацию (в Донецке 2ГИС популярен).
3. **Яндекс Вебмастер** (webmaster.yandex.ru) — добавьте сайт и `sitemap.xml`, чтобы Яндекс быстрее его проиндексировал.
4. **Яндекс Метрика** (metrika.yandex.ru) — создайте счётчик, его номер вставьте в `js/config.js` → `metrikaId`. Уже настроены цели: `lead_form` (заявка), `lead_messenger`, `click_phone`, `click_messenger`.
5. Ссылку на сайт — в профили Telegram/VK/Авито.

## Как добавить новые фото работ
1. Подготовьте два файла: большое фото (по длинной стороне ~1600 px) и превью (~640 px), JPG.
2. Назовите по порядку, например `77.jpg` и `77-t.jpg`, положите в нужную папку, например `img/works/ograzhdeniya/`.
3. В `js/works.js` в нужной категории в конец списка `items` добавьте `["77",1600,1200]` (имя, ширина, высота).
4. В `index.html` увеличьте номер версии у `js/works.js?v=2` → `?v=3`, чтобы браузеры посетителей увидели изменения сразу.

Обложка категории на главной задаётся полем `cover` в `js/works.js`. Какие категории показываются крупными карточками — массив `MAIN_CATS` в начале `js/main.js`.

## Если сайт открыт на GitHub Pages
Там PHP не работает, поэтому форма не отправляет заявку сама, а предлагает отправить готовый текст в Telegram/WhatsApp/MAX или позвонить. Для полноценной формы нужен хостинг с PHP (Timeweb).
