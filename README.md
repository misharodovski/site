# Истая Кузница — сайт-визитка

Готовый сайт кузницы: Донецк + работа по всей ДНР. Обычный статический сайт (HTML/CSS/JS) с одним PHP-файлом для формы заявок. Ни базы данных, ни CMS не требуется.

## Что внутри

| Файл / папка | Зачем |
|---|---|
| `index.html` | главная страница |
| `politika.html` | политика конфиденциальности (152-ФЗ) |
| `404.html` | страница «не найдено» |
| `js/config.js` | **НАСТРОЙКИ: телефон, мессенджеры, почта, часы работы, Метрика** |
| `send-config.php` | **НАСТРОЙКИ ФОРМЫ: почта (SMTP) и Telegram для заявок** |
| `send.php` | обработчик формы (не трогать) |
| `max-setup.php` | помощник: показывает ваш ID в MAX при настройке бота (работает только при `'setup' => true`) |
| `ДОБАВИТЬ ФОТО.cmd` | **добавление новых фото работ** (см. раздел ниже) |
| `js/works.js` | список фото работ по категориям (обновляется автоматически) |
| `img/works/<категория>/` | реальные фото: `NN.jpg` (1600 px) и `NN-t.jpg` (превью 640 px) |
| `img/hero.jpg`, `img/og.jpg` | фото главного экрана и картинка для ссылок в мессенджерах |
| `.htaccess` | кэширование, сжатие, закрытие служебных файлов |
| `robots.txt`, `sitemap.xml` | для Яндекса и Google |
| `data/leads.csv` | появится сам: копия всех заявок (открывается в Excel, из интернета закрыт) |

## Запуск на Timeweb — по шагам

### 1. Хостинг
1. Зарегистрируйтесь на timeweb.com → «Виртуальный хостинг» → тариф **Optimo** (или любой другой, где есть PHP).
2. Первые 10 дней — бесплатный тест. **Учтите:** на тестовом аккаунте Timeweb закрывает отправку почты из скриптов, поэтому полностью проверить форму получится после оплаты. Сам сайт работает и на тесте.

### 2. Домен — `istaya-kuznica.ru`
Сайт уже настроен на адрес **istaya-kuznica.ru** (на 12.11.2026 он свободен; созвучный `istaya-kuznya.ru` — как в вашей почте — тоже свободен).
1. В панели: «Домены» → «Зарегистрировать» → `istaya-kuznica.ru`. При годовой оплате Timeweb даёт домен .RU/.РФ в подарок.
2. Для доменов .ru/.рф администратор домена должен пройти **идентификацию через Госуслуги** — в панели Timeweb есть кнопка для этого. Пока она не пройдена, домен может не делегироваться.
3. Привяжите домен к сайту: «Сайты» → ваш сайт → «Привязать домен».
4. Если выберете другой домен — замените `istaya-kuznica.ru` на него в `index.html` (3 места в начале), `robots.txt` и `sitemap.xml`.

### 3. Загрузка файлов
1. В панели: «Файловый менеджер» → откройте папку сайта → `public_html`.
2. Удалите оттуда заглушку `index.html` от Timeweb (если есть).
3. Загрузите архив `kuznica-site.zip` → правый клик → «Разархивировать». Если архив не загружается из-за размера (≈111 МБ) — загрузите файлы по FTP (например, программой FileZilla; доступы FTP — в панели Timeweb).
4. **Важно:** `index.html` должен лежать прямо в `public_html`, а не в подпапке `public_html/kuznica-site/`. Если он оказался в подпапке — выделите всё её содержимое и перенесите на уровень выше.
5. Проверьте, что файл `.htaccess` тоже на месте (в файловом менеджере включите показ скрытых файлов).

### 4. HTTPS (замок в браузере)
«Сайты» → настройки → **SSL-сертификаты** → «Заказать» бесплатный Let's Encrypt → после выпуска включите **«Перенаправлять с HTTP на HTTPS»**.

### 5. Контакты — уже заполнены (`js/config.js`)
Телефон +7 (949) 452-20-65, MAX на этом же номере, почта 1istaya_kuznya@mail.ru, Пн–Сб 9:00–18:00, г. Донецк.
Когда появится ссылка на ваш профиль в MAX (в приложении: Профиль → Поделиться), вставьте её в `max: '...'` — кнопка MAX на сайте сразу станет открывать чат. Пока ссылки нет, кнопка копирует номер.

### 6. Чтобы заявки приходили — `send-config.php` (почта + MAX)
> ⚠️ Пароль и токен вписывайте **только в копию файла на хостинге** (Файловый менеджер Timeweb → правый клик → «Редактировать»). Не сохраняйте их в репозиторий GitHub — он публичный.

**Почта 1istaya_kuznya@mail.ru** — заявка приходит письмом самому себе. Всё уже заполнено, кроме пароля:
1. Зайдите в почту mail.ru → нажмите на свой адрес → «Пароль и безопасность» → **«Пароли для внешних приложений»** → «Добавить».
2. Назовите «Сайт», доступ — «Только почта (SMTP)» → скопируйте показанный пароль.
3. Вставьте его в `send-config.php` → блок `smtp` → `'pass' => '...'`. Обычный пароль от почты не подойдёт.

**MAX** — заявка приходит сообщением от бота вашей кузницы:
1. Откройте **business.max.ru** → войдите по номеру +7 949 452-20-65 → подтвердите ИП (ИП Зеленецкий А. А.).
2. «Чат-боты» → «Создать бота» (например, «Истая Кузница — заявки»). Бот проходит модерацию MAX.
3. После одобрения: бот → ⋮ → «Настройки» → скопируйте **токен** → вставьте в `send-config.php` → блок `max` → `token`.
4. В приложении MAX найдите своего бота и напишите ему «привет».
5. В `send-config.php` временно поставьте `'setup' => true`, откройте `https://istaya-kuznica.ru/max-setup.php` — там будет ваш **user_id**.
6. Впишите его в `user_id`, поставьте `'enabled' => true` и **верните `'setup' => false`**.

Пока бот на модерации, заявки приходят на почту. Даже если оба канала не работают, заявка сохранится в `data/leads.csv`.

## Продвижение (бесплатно, очень рекомендуется)
1. **Яндекс Бизнес** (yandex.ru/sprav) — карточка кузницы на Яндекс Картах и в поиске. Для местного бизнеса даёт больше всего обращений. Укажите сайт, телефон, фото работ, зону обслуживания — ДНР.
2. **2ГИС** — добавьте организацию (в Донецке 2ГИС популярен).
3. **Яндекс Вебмастер** (webmaster.yandex.ru) — добавьте сайт и `sitemap.xml`, чтобы Яндекс быстрее его проиндексировал.
4. **Яндекс Метрика** (metrika.yandex.ru) — создайте счётчик, его номер вставьте в `js/config.js` → `metrikaId`. Уже настроены цели: `lead_form` (заявка), `lead_messenger`, `click_phone`, `click_messenger`.
5. Ссылку на сайт — в профили Telegram/VK/Авито.

## Как добавить новые фото работ (на компьютере с Windows)
Папку сайта храните у себя на компьютере — это рабочая копия, из неё добавляются фото.

1. **Первый раз:** дважды щёлкните **`ДОБАВИТЬ ФОТО.cmd`** в папке сайта. Появится папка **`_НОВЫЕ ФОТО`** с подпапками по категориям сайта («Ограждения и ворота», «Балконы», «Лестницы и перила»…).
2. **Разложите фото** по подпапкам — сколько угодно, прямо с телефона или фотоаппарата, любого размера. Нужна новая категория — создайте подпапку с её названием (например, «Перголы»).
3. **Снова запустите `ДОБАВИТЬ ФОТО.cmd`.** Программа сама:
   - повернёт фото правильно и уменьшит до 1600 px (+ превью 640 px) — сайт останется быстрым;
   - уберёт из файлов геолокацию (координаты домов клиентов не попадут в интернет);
   - поставит новые фото **первыми** в их категории;
   - пропустит фото, которые уже добавлялись раньше;
   - перенесёт обработанные оригиналы в `_НОВЫЕ ФОТО\_готово`;
   - соберёт архив **`_ОБНОВЛЕНИЕ ДЛЯ ХОСТИНГА.zip`** — только новые файлы.
4. **Загрузите обновление на сайт:** Timeweb → Файловый менеджер → `public_html` → загрузите `_ОБНОВЛЕНИЕ ДЛЯ ХОСТИНГА.zip` → правый клик → «Разархивировать» с заменой файлов → удалите архив с хостинга.

**Форматы:** JPG, PNG, BMP, GIF, TIFF. Фото **HEIC с iPhone** программа не читает — в iPhone включите «Настройки → Камера → Форматы → Наиболее совместимый», или перешлите фото себе через мессенджер (они станут JPG).

Обложка категории на главной — поле `cover` в `js/works.js` (номер фото). Какие категории показываются крупными карточками — массив `MAIN_CATS` в начале `js/main.js`. Подписи к категориям — поле `text` в `js/works.js`.

## Если сайт открыт на GitHub Pages
Там PHP не работает, поэтому форма не отправляет заявку сама, а предлагает отправить готовый текст в Telegram/WhatsApp/MAX или позвонить. Для полноценной формы нужен хостинг с PHP (Timeweb).
