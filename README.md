# Истая Кузница — фронтенд сайта

Одностраничный сайт-визитка мастерской художественной ковки. Чистые HTML/CSS/JS без сборки и зависимостей + PHP-обработчик формы. Продаж и оплаты на сайте нет, в подвале есть пометка «не является публичной офертой (ст. 437 ГК РФ)».

## Структура

```
index.html          главная страница
politika.html       политика обработки персональных данных (шаблон, заполнить реквизиты)
404.html            страница «не найдено»
send.php            обработчик формы «Обсудить проект» → e-mail
css/style.css       все стили
js/main.js          анимации и интерактив
img/                изображения (сейчас — временные, вырезаны из макетов)
video/              сюда положить forge.mp4 (и по желанию forge.webm) для кнопки «Посмотреть видео»
data/               резервная копия заявок (leads.csv), закрыта от доступа из браузера
.htaccess           настройки Apache (кэш, безопасность, 404, HTTPS — раскомментировать)
nginx.conf.example  пример конфигурации для VPS с nginx
robots.txt, sitemap.xml
```

## Что заменить перед запуском

1. **E-mail для заявок** — `send.php`, переменная `$TO`.
2. **Контакты** — телефон, почта, адрес, часы работы в `index.html` (блок «Контакты», мобильное меню, подвал) и в `politika.html`.
3. **Домен** — `istaya-kuznica.ru` в `index.html` (canonical), `robots.txt`, `sitemap.xml`.
4. **Реквизиты оператора ПДн** в `politika.html` (всё в [квадратных скобках]). Текст лучше показать юристу.
5. **Фотографии** — положите настоящие фото в `img/` под теми же именами (тогда код трогать не нужно):
   - `hero.jpg` — главный экран, горизонтальное ~2400×1300
   - `gate.jpg` — блок «Металл становится частью архитектуры», ~2000×700
   - `swirl.jpg` — фон «Философия», ~2400×700
   - `p1.jpg … p4.jpg` — проекты, ~1200×560 (тексты проектов для всплывающего окна — в `js/main.js`, массив `PROJECTS`)
   - `s1.jpg … s7.jpg` — этапы процесса, квадрат ~600×600
   - `m1.jpg … m3.jpg` — мастера, ~800×980
   - `matleaf.jpg`, `mt1.jpg … mt4.jpg` — материалы
   - `seal.jpg` — фон блока контактов
   Если меняете `hero.jpg` на другой кадр, поправьте в `js/main.js` точки `PT_METAL` / `PT_FIRE` — это место на фото (в долях ширины и высоты), откуда летят искры и где светится металл.
6. **Видео** — `video/forge.mp4`. Пока файла нет, в окне показывается аккуратная заглушка.

## Размещение на хостинге

Обычный хостинг (Beget, Timeweb, REG.RU и т.п.):
1. Загрузите **содержимое** папки в корень сайта (`public_html` / `www`), включая скрытый файл `.htaccess`.
2. Убедитесь, что включён PHP 7.2+ (подойдёт любой современный).
3. Выпустите бесплатный SSL-сертификат в панели и раскомментируйте блок HTTPS в `.htaccess`.
4. Отправьте тестовую заявку. Если письмо не пришло — проверьте спам и `data/leads.csv` (заявка сохраняется туда в любом случае). На некоторых хостингах нужно создать ящик на домене сайта, чтобы `mail()` работал.

VPS с nginx — см. `nginx.conf.example`.

Локальный просмотр: просто откройте `index.html` в браузере (форма отправляться не будет — ей нужен PHP-сервер) или запустите `php -S localhost:8000` в папке сайта.

## Анимации

- прелоадер с эмблемой (при повторном заходе в течение сессии — короткий)
- главный экран: построчное появление заголовка, «раскалённый» перелив на «Они рождаются в огне», мерцание огня и металла, угольки и искры от ударов молота (canvas), клик по экрану — сноп искр, лёгкий параллакс от мыши
- бегущая строка направлений, появление блоков при прокрутке, параллакс фото, счётчики, отрисовка «∞»
- линия прогресса процесса, слова цитаты «загораются» по мере прокрутки
- карточки проектов с открытием в окне и перелистыванием (стрелки клавиатуры, Esc)
- медный курсор на десктопе, прячущаяся шапка, мобильное меню
- при системной настройке «уменьшить движение» анимации отключаются

## Шрифты

Cormorant Garamond и Manrope подключены с Google Fonts. Если нужно полностью исключить сторонние запросы, скачайте woff2 (например, через google-webfonts-helper), положите в `fonts/`, подключите через `@font-face` в начале `css/style.css` и удалите `<link>` на fonts.googleapis.com из HTML.
